# Superstore Data Analysis Dashboard

## Project Overview
The **Superstore Data Dashboard** is an Excel-based data analysis and visualization project designed to explore sales performance, profitability, product categories, customer segments, and regional business performance.

The project uses Microsoft Excel features such as Pivot Tables, Pivot Charts, and dashboard elements to summarize and analyze business data.

## Dataset Information
- **Dataset:** Superstore Sales Data
- **Total Records:** 51,290
- **Total Columns:** 21
- **File Format:** Excel Macro-Enabled Workbook (.xlsm)

## Workbook Structure

The workbook contains three worksheets:

### 1. Superstore
Contains the original sales dataset with order, customer, product, shipping, sales, and profit information.

### 2. Pivot
Contains Pivot Table summaries used for analyzing:
- Sales by region
- Profit by product category
- Sales and profit by region
- Sales by state
- Sales by product category
- Sales and profit by customer segment
- Sales by region and customer segment
- Overall business performance
- Yearly sales and profit

### 3. Dashboard
Contains the dashboard worksheet for presenting business insights and visual analysis.

## Project Objectives
1. Analyze overall sales and profit performance.
2. Identify high-performing regions.
3. Understand product category performance.
4. Analyze customer segment contributions.
5. Compare yearly sales and profit.
6. Identify important business trends using Excel dashboards.

## How to Use
1. Download or open the Excel workbook.
2. Navigate to the **Dashboard** worksheet.
3. Explore the dashboard and available interactive elements.
4. Visit the **Pivot** worksheet to examine summarized data.
5. Visit the **Superstore** worksheet to access the original dataset.

## Conclusion
This project demonstrates how Microsoft Excel can be used to transform raw sales data into meaningful business insights through data analysis, Pivot Tables, and dashboard visualization.

The dashboard helps users understand sales performance, profitability, customer segments, and regional trends to support data-driven decision-making.
